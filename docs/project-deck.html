The problem

Tool use is more than language generation.

01

Discover

Interpret raw tools/list descriptions and choose the right capability.

02

Conform

Emit a valid tool name and schema-correct arguments—not merely plausible prose.

03

Sequence

Use observations to choose the next call, avoid loops, and stop at the right time.

Small local models can understand the civic issue yet still fail at protocol formatting, routing, or multi-step control.

Project purpose

Give the model less to get wrong.

A portable Purpose Pack turns an MCP-backed objective into a compact, validated workflow. The local model handles the narrow language task; deterministic code handles control.

Model owns

  • Understand the user’s civic issue
  • Extract a concise description
  • Identify category and location

Compiler owns

  • Tool routing and sequencing
  • Schema validation and call limits
  • Result handling and verification

The Purpose Pack lives in the client. Existing MCP servers need no new endpoints or code.
